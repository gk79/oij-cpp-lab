# C++ Lab — OIJ

56 ćwiczeń języka C++17 i STL dla przygotowujących się do II etapu Olimpiady Informatycznej Juniorów. Każde zadanie ma pełną treść, specyfikację wejścia/wyjścia, przykład z wyjaśnieniem oraz krótką ściągę.

## GitHub Pages

Repozytorium zawiera statyczną stronę. Aby ją opublikować, w **Settings → Pages** wybierz **Deploy from a branch**, gałąź **master**, katalog **/(root)** i zapisz. Adres: https://gk79.github.io/oij-cpp-lab/.

Postępy w `localStorage` przeglądarki użytkownika; eksport/import JSON. Brak logowania i serwera.
